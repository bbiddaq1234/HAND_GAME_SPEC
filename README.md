# 오브 가디언 (Orb Guardian)

웹캠으로 양손 21개 관절을 인식해서 3D 스켈레톤으로 그리고, 날아오는 오브를 손으로 쳐내는 전체화면 브라우저 게임입니다.
설계 문서는 [HAND_GAME_SPEC.md](HAND_GAME_SPEC.md)에 있습니다.

## 실행 방법

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다.
2. 이 폴더에서 터미널을 열고 아래 명령을 입력합니다.
   ```bash
   npm install
   npm run dev
   ```
3. 브라우저(크롬·엣지)에서 `http://localhost:5173`을 엽니다.
4. **[게임 시작]** 클릭 → 카메라 **허용** → 양손을 2초 동안 보여주면 게임이 시작됩니다.

> `index.html`을 더블클릭해서 열면 카메라가 동작하지 않습니다. 반드시 `npm run dev`로 실행하세요.

## 조작법

| 동작 | 효과 |
|---|---|
| 🎵 메트로놈 박자에 맞춰 치기 | 오브는 4박 뒤 박자에 손 앞에 도착. PERFECT(±0.1초) ×1.5 · GOOD(±0.2초) ×1 · OK ×0.5. 30초마다 BPM +10 |
| 🖐️ 같은 색 손으로 오브 치기 | +10점 (다른 색 손은 +2점). 왼손 = 파랑, 오른손 = 빨강 |
| ✊ 주먹 쥐고 치기 | 점수 2배 (쿨타임 3초) |
| ✋ 손바닥 펴기 | 방패: 판정 범위가 넓어짐 |
| 👏 양손 박수 | 왼손 ⇄ 오른손 색이 바뀜. 게이지 100%면 필살기(화면의 오브 전부 제거)도 발동 |
| 🙌 양손 가까이 / 멀리 | 가까우면 스켈레톤이 커지고(최대 1.8배) 멀면 작아짐(최소 0.6배). 커지면 오브를 치기 쉬워짐 |
| 🤏 핀치 (엄지+검지) | 일시정지에서 이어하기 |
| 양손 펴고 1초 유지 | 게임 오버 화면에서 다시하기 |
| **D 키** | 카메라 미리보기 + 디버그 정보 켜기/끄기 |

## 처음 실행할 때 확인할 것

**D 키**를 누르고 **오른손**을 들어 보세요. 미리보기에 **"왼손"**으로 표시되면
`src/config.js`의 `SWAP_HANDEDNESS` 값을 `true` ↔ `false`로 바꿉니다.

손이 너무 앞뒤로 튀거나 반응이 느리면 `src/config.js`의 `SMOOTHING`, `JOINT_DEPTH_GAIN` 값을 조절하세요.
게임 난이도(속도, 생명, 점수)도 모두 `src/config.js`에서 바꿀 수 있습니다.

## 점검 · 빌드 · 배포

```bash
npm run check   # 제스처 판정 자체 점검
npm run build   # dist 폴더에 배포용 파일 생성
```

**Vercel 배포:** GitHub에 올림 → vercel.com 로그인 → **Add New → Project** → 저장소 선택 → **Deploy**
(Framework Preset은 Vite로 자동 선택됩니다.) 배포된 `https://` 주소에서 카메라가 동작합니다.

## 파일 구조

```
src/main.js          시작점: 상태 흐름과 게임 루프
src/config.js        숫자 설정 모음
src/camera.js        웹캠 켜기 + 오류 안내
src/handTracker.js   MediaPipe 손 인식 + 3D 좌표 변환 + 떨림 보정
src/handSkeleton.js  관절·뼈 3D 렌더링
src/gestures.js      핀치·주먹·손바닥·박수 판정
src/game.js          오브·충돌·점수·생명·레벨
src/scene.js         3D 장면·조명·리사이즈·전체화면
src/ui.js            화면 전환·HUD·효과음·디버그 미리보기
```

웹캠 영상은 브라우저 안에서만 처리되며 어디에도 저장·전송되지 않습니다.
